# References and reading guide

Primary sources inform the terminology and further study. The examples in this repository are original illustrative specifications, not reproductions of full standardized models.

| Publication | Use in this repository |
| --- | --- |
| [NIST IR 8539: Security Property Verification by Transition Model](https://csrc.nist.gov/pubs/ir/8539/final) | Transition models, temporal property specifications, and further model-checking study |
| [NIST SP 800-162: Guide to Attribute Based Access Control](https://csrc.nist.gov/pubs/sp/800/162/upd2/final) | Attributes and policy-based authorization |
| [NIST IR 6192: A Revised Model for Role-Based Access Control](https://csrc.nist.gov/pubs/ir/6192/final) | Role-model foundations and further study of hierarchy |
| [NIST SP 800-192: Verification and Test Methods for Access Control Policies/Models](https://csrc.nist.gov/pubs/sp/800/192/final) | Policy/model verification and testing |
| [NIST SP 800-160 Vol. 1 Rev. 1: Engineering Trustworthy Secure Systems](https://csrc.nist.gov/pubs/sp/800/160/v1/r1/final) | Broader systems security engineering and assurance context |

## Reading order

1. Read the repository method and worked example.
2. Use SP 800-162 and IR 6192 to deepen authorization modeling.
3. Use SP 800-192 to plan verification and conformance evidence.
4. Use SP 800-160 to place models within the system life cycle.

Citing a publication does not establish conformance to it.
